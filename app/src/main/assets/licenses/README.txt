Brush Alarm license bundle

This directory is packaged into production and test APKs so recipients can
inspect the applicable notices without network access.

Project files:
- BrushAlarm-GPL-3.0-only.txt: software source license
- BrushAlarm-Model-License.md and -EN.md: separate model boundary
- BrushAlarm-Third-Party-Notices.md and -EN.md: dependency/provenance index

Upstream license texts:
- Apache-2.0.txt:
  https://www.apache.org/licenses/LICENSE-2.0.txt
- CC-BY-NC-4.0.txt:
  https://creativecommons.org/licenses/by-nc/4.0/legalcode.txt
- ONNX-Runtime-LICENSE.txt:
  https://github.com/microsoft/onnxruntime/blob/v1.27.0/LICENSE
- ONNX-Runtime-ThirdPartyNotices.txt:
  https://github.com/microsoft/onnxruntime/blob/v1.27.0/ThirdPartyNotices.txt

The original upstream texts control. Inclusion here does not state that every
asset has the same license.
