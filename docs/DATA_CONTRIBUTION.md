# 志愿者刷牙视频贡献原则

> 当前状态：**尚未开放征集，也没有可用的官方上传入口。**

刷牙视频可能包含正脸、家庭环境、浴室和作息信息，属于高敏感度材料。公开 GitHub
仓库不接受任何原始视频。

## 开放前必须完成

- 建立访问受限、传输加密的私密上传通道；
- 公布维护者身份和可联系渠道；
- 使用单独的知情同意文本，不把同意埋在普通软件许可里；
- 定义数据控制人、访问人员、保存位置、备份和删除流程；
- 明确用途只限本项目的非商业训练、验证和研究；
- 提供撤回方法、截止点和合理的回应时限；
- 设计贡献者级别的数据划分，防止同一人跨训练/测试集；
- 完成当地适用隐私和肖像权规则的独立法律审阅。

## 计划中的最低要求

- 贡献者年满 18 周岁并能对视频和其中肖像授权；
- 视频中不出现未成年人或未单独同意的旁人；
- 避免拍摄药物、地址、证件、镜面反射和其他可识别物；
- 同时征集真实刷牙、停止动作和嘴边相似负样本，但不诱导危险行为；
- 原始数据不公开、不进入 Git、不随模型发布；
- 只发布经过训练得到的权重、聚合指标和不含个人身份的数据说明。

## 撤回与派生模型

贡献者应能在数据冻结/指定训练截止点前撤回，并要求删除仍由维护者控制的原始文件。
一旦模型已经公开分发，维护者可以停止未来使用并从后续版本删除影响，但无法从他人
已经下载的历史模型副本中可靠移除单个样本的影响。该限制必须在贡献前明确说明。

## 许可关系

软件许可不自动覆盖志愿者视频。每位贡献者需要单独签署数据贡献同意。示例草案见
[`DATA_CONTRIBUTION_CONSENT_TEMPLATE.md`](DATA_CONTRIBUTION_CONSENT_TEMPLATE.md)；
它不是法律意见，正式征集前应按维护者所在地和参与者所在地进行审阅。
